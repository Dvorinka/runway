Every push
is a departure.

Two series. Series B — the cockpit is production thinking: real information architecture, filters, selection, density. Aviation lives in the system — status names, the flight-path progress track, the ticket stub — not in the chrome. Series A — the museum is the pure-metaphor set: beautiful, less shippable. Same six deployments everywhere so the ergonomics compare directly.

SERIES B — THE COCKPIT · SHIPPABLE UX
06

Flightline

The honest evolution of the current dashboard. Signature element: the logo's approach path flattened into a flight-path progress track on every row — QUEUE→TAXI→CLIMB→FINAL→LANDED. Filters, expandable detail, instrument counters.
→
07

Apron

Operations board: deployments parked on a time axis by environment lane instead of a list. Deploy frequency and duration are visible at a glance — the thing teams actually ask. Light ops-whiteboard palette.
→
08

Manifest

Every deploy files a flight plan: numbered sections (route, aircraft, cargo, clearance, remarks), a stamped disposition. Document UX — linear, scannable, prints beautifully. Aviation as paperwork, not decoration.
→
09

Ticket

Deployments as boarding passes: REPO → ENV route letters, gate = alias, barcode = sha, perforated stub that tears open into the flight record. Playful but a real, dense, filterable card grid.
→
10

Radio

The app as a command frequency. Channels for views, transmissions for events, a transmit line that filters and runs the same verbs as the CLI/MCP. Keyboard-only, maximum density — the devs' tower.
→

SERIES A — THE MUSEUM · PURE METAPHOR
01

Tower

The dashboard as an ATC radar scope. Deployments are tracked flights — callsigns are SHAs, altitude is build progress, aliases are squawk codes. Phosphor orange on ink, live sweep, teletype feed.
→
02

Strip Bay

Analog flight-progress strips in metal rack bays — the paper system real towers used for decades. Rubber-stamp statuses, grease-pencil notes, perforation edges. The only light-mode direction; tactile, warm, human.
→
03

Departures

A Solari split-flap board under airport wayfinding signage. Rows flap-shuffle into place, BOARDING blinks, announcements crawl. Pure typographic kinetic energy — nothing else in devtools looks like this.
→
04

Sectional

The whole instance as an aeronautical chart. Projects are airfields with runway glyphs, teams are airspace, deployments flow along corridors from the Git sector. Cartographic, parchment, a chart supplement for the data.
→
05

Flight Recorder

The app inside the black box — which is orange, like the brand. Riveted casing, serial plate, toggle-switch nav, amber LCD memory dumps. Industrial object design: your deploys, crash-survivable.
